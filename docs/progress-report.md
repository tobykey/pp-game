# 밤샘 작업 보고서 (2026-10-18 밤 → 10-19 아침)

목표였던 **프로토타입 v0.2 = 챕터 0을 처음부터 끝까지 플레이**를 달성했다. 추가 목표였던 챕터 1 도입은 **"챕터 1 맛보기"**(간주 → 1절의 기타 침묵 시연)로 만들었다.

---

## 1. 바로 해 보기

1. VS Code 터미널에서 `npm run dev` → `http://localhost:5173`
2. **"현을 깨우기"**로 처음부터 시작 (헤드폰 권장. 박을 들어야 한다)
3. 특정 장면만 다시 보고 싶으면 시작 화면 아래의 **"장면 바로 가기"**에서 고른다

전체 플레이는 챕터 0이 약 3~5분, 맛보기가 약 30초다.

## 3. 확인해 주실 것 (체험 순서대로)

1. **눈뜸:** 심장 소리에 맞춰 먹이 번지며 장면이 그려지는 느낌이 괜찮은지
2. **배 그림:** 뒤쪽에 기타를 안은 '나', 뱃머리에 누운 그 사람, 내 쪽으로 뻗은 손, 핫핑크 띠가 보이는지
3. **노 젓기 손맛 (가장 중요):**
   - 박동에 맞춰 긁을 때 배가 나아가는 느낌이 있는지
   - 박을 놓치면 기우뚱하는 게 납득되는지
   - 너무 엄격하거나 너무 헐렁하지 않은지
4. **훅:** D♭6(A S D F 네 키)를 잡기 편한지. 130 BPM 박 판정이 적당한지
5. **물그림자·천 조각:** 띠가 짧아지는 게 너무 잘 보이거나, 아예 안 보이지는 않는지
6. **후렴 1 예고:** 30초 남짓의 '꿈속의 꿈'이 신나는지. 형광이 과하지 않은지
7. **챕터 1 맛보기:** 1절에서 기타가 울리지 않는 연출이 어떤 느낌인지 → 결정 3번
8. **소리 밸런스:** 심장·드럼·베이스·기타의 크기가 서로 맞는지 (저는 소리를 직접 들을 수 없어서 숫자로만 맞췄습니다)
9. **두 번째 심장:** 헤드폰으로 들으면 심장 소리 뒤에 오른쪽에서 아주 희미한 박동이 하나 더 들리는지 (복선 5)

## 5. 알려진 문제·아쉬운 점

- **ff 연출이 자주 터짐:** 아주 빠르게 긁으면 줄마다 ff 연출이 터져서(원본 프로토타입과 같은 동작), 노를 빠르게 저으면 화면이 꽤 시끄럽다. 보통 속도(테스트 기준 mf)에서는 괜찮다. 노 젓기 장면에서만 줄일지 정해 주세요
- **챕터 1 맛보기를 시작하는 방법이 숨어 있다:** 챕터 0 끝에서 5초 뒤 안내가 뜨고, 줄을 긁어야 넘어간다
- **휴대폰:** 화면 배치는 원본처럼 대응하지만, 노 젓기와 훅을 터치로 끝까지 해 보지는 못했다
- **소리:** 합성음이다. MR을 박에 맞춰 트는 것은 다음 단계로 미뤘다

## 6. 검증한 것

- 타입 검사(`tsc`), 빌드 모두 통과
- 헤드리스 브라우저 자동 플레이:
  - 챕터 0 전 구간을 처음부터 끝까지 막힘 없이 통과했다 (노 젓기 26회, 훅 4/4, 후렴 코드 D♭ E♭ Cm F 확인)
  - 챕터 1 맛보기: 간주 8마디 → 1절 8마디(Fm D♭ E♭ A♭ D♭ E♭ C C) 순서를 확인했다
- 사람처럼 흔들리게 치는 노 젓기 테스트: 박에서 ±0.08초 흔들려도 29회 만에 도착했다. 세기는 mf로 나와 ff 폭발 없음
- 콘솔 오류 없음
