# 아이디어 보관함

바로 구현하지 않고 모아 두는 곳. 로드맵 단계가 끝날 때마다 검토해서 넣을지 정한다.

- 습관처럼 치던 자유 연주 코드가 사실 어떤 퍼즐의 정답이었다는 연출
- 플레이어가 편곡 버전을 직접 고를 수 있는지, 맵이 정하는지
- 맵 전환 시 편곡이 끊기지 않고 자연스럽게 이어지는 방식
- 6현 기타 말고 다른 악기도 등장시키기 (조작 수단으로 쓸지, 연출로만 쓸지 포함)

### 2026-10-19 (Toby)
- **숙련되면 코드 칩이 사라지는 연출:** 나~중에 플레이어가 코드 잡는 법에 익숙해졌을 때, 상단 운지표(코드 버튼)가 사라진다. 손이 기억하는 연주가 되는 순간. 이야기와 엮을 수도 있다 (예: 그 사람이 보여 주던 운지표 = 그 사람의 손글씨가 흐려짐)

### 2026-10-19 플레이 피드백에서 나온 것
- **오른손 세기 조절:** 6줄을 다 긁으려면 빨리 긋게 되어 ff가 자주 나온다. 실제 기타처럼 세기를 따로 조절할 방법 후보
  - 긁는 속도 대신 '긁는 길이'나 '줄 위에 머문 시간'으로 세기 판정
  - 마우스 버튼 구분 (왼쪽 = 보통, 오른쪽 = 세게) 또는 휠로 오른손 힘 조절
  - Shift(팜뮤트)처럼 '세게' 전용 키, 또는 반대로 평소엔 mf 고정이고 특정 키를 누를 때만 ff
  - 터치 화면은 누르는 압력 사용
- **코드 키 배치:** Q A Z / W S X처럼 세로로 잡는 모양이 어색하다. 가로 행 위주 배치, 손 모양이 편한 배치 등 대안 검토 (아이디어 자체는 유지)
- **띠가 짧아지는 복선이 거의 안 보인다:** 기획자도 눈치채기 어려웠다. 천 조각을 감는 순간의 짧은 애니메이션이나 컷신(띠가 풀려 나가는 모습)으로 보강 → 디테일 잡기 단계에서
- **후렴 1 예고('꿈속의 꿈')의 의도가 잘 전달되지 않는다:** 꿈이라는 걸 알 수 있는 연출(화면 테두리, 색감, 들어가고 나오는 전환) 보강 필요
- **챕터 1 맛보기 시작 방법:** 지금은 챕터 0 끝에서 줄을 긁어야 해서 숨어 있다. 본편에서는 자연스럽게 이어지게

### 2026-10-21 (Toby 요청 검토)
- 격돌 요구 속도를 계단 대신 비탈로 서서히 올리기, 기억 테스트 답하는 법, 다른 퍼즐 게임(위트니스·Before Your Eyes·Baba Is You·오브라 딘·고로고아·네크로댄서·저니 등)에서 빌려 올 기믹 → `docs/benchmark-2026-10-21.md`

### 2026-10-22 (Toby, 챕터 6·엔딩 플레이 뒤)
- **기믹 실패 = 꿈이 되감긴다 (기시감):** 기믹에서 실패하면 '죽음'처럼 그 기믹 구간의 처음으로 돌아간다. 꿈이 같은 곳으로 되돌아가는 듯한 기시감. 지금까지의 '실패 없는 구조' 원칙을 바꾸는 결정이라 범위·규칙을 정한 뒤 구현
- **후반부의 감동이 약하고 갑자기 끝나는 느낌** → 감동 포인트 보강 필요
- **체리필터 '피아니시모'가 떠오르지 않는다** → 원곡 반주(MR)를 실제로 쓰는 방향 검토 (로컬 MR 있음, 저장소에는 올리지 않음)
