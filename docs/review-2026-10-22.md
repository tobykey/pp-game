## 2. 성능 (프레임이 떨어지지 않게)

### 무엇이 무거웠나 → 어떻게 했나
그리기 구간마다 시간을 재는 측정기를 만들었다 (`?prof`, `src/render/prof.ts`, 개발 서버에서만 켜짐).

| 원인 | 전 | 후 | 방법 |
| --- | --- | --- | --- |
| 기억 테스트 답 그림의 **흐림 필터** (렉의 주범) | 38.7ms | 0.7ms | 필터를 없애고 한지 빛 안개 + 가로 붓 자국으로 '흐릿함'을 그림 |
| 안개 (모든 장면) | 9ms | 3ms | 1/4 해상도에 그려 수평선 근처 띠만 늘려 붙임, 안개가 없으면 건너뜀 |
| 박의 비네트 (모든 장면) | 4.8ms | 1.0ms | 화면 크기가 바뀔 때만 실제 해상도로 한 번 그려 두고 투명도만 바꿔 붙임 |
| 1절 색 빠짐 | 7ms | 5ms | 줄·악보 위쪽(바다까지)만 칠함 |

### 장면별 (소프트웨어 그리기 기준, 프레임당 ms)
| 장면 | 밤 시작 | 지금 |
| --- | --- | --- |
| 노 젓기 (챕터 0) | 18.9 | 9.8 |
| 밤의 방 (1절) | 26.7 | 14.4 |
| 등대의 바다 (챕터 3) | 19.3 | 10.7 |
| 기억 테스트 (챕터 5) | **49.6** | 8.7 |
| 격돌 ① (챕터 4, 화면이 조여 오는 중) | 16.0 | 14.2 |
| 마지막 관문 (챕터 6) | — | 7.2 |
그래픽 카드가 있는 보통 컴퓨터에서는 이보다 훨씬 가볍다.

### 앞으로 지킬 규칙 (새 연출을 만들 때)
- `ctx.filter`(흐림 등)는 쓰지 않는다. 흐릿함은 반투명 한지 칠·붓 자국으로
- 화면 전체를 덮는 부드러운 층(안개·그림자·빛 번짐)은 **미리 그려 두거나 낮은 해상도로**
- `shadowBlur`(빛 번짐)는 작은 글자·작은 그림에만, 순간적으로만
- 새 장면을 만들면 `?prof`로 재 보고, 소프트웨어 그리기에서 16ms(60프레임)를 넘지 않게

## 3. 코드 구조

### 지금 모양
| 폴더 | 내용 | 비고 |
| --- | --- | --- |
| `data/` | 챕터별 장면 순서·배치·문구·패턴 (`chapter0~6.ts`), 곡 구성, 코드 | 대사·퍼즐 정의는 데이터로 분리 (규칙대로) |
| `story/` | 챕터별 장면 진행, 공통 도구 | 이번에 **`scene.ts`**(once·goLater·등록)와 **`sfx.ts`**(화음 소리)로 일곱 챕터의 복붙 코드를 한곳에 모음, **`counter.ts`**(파란·노란 빛 판정) |
| `render/` | 그리기: 공통(`draw.ts`) + 챕터별 그림(`chapter1~6Art.ts`), 컷신(`cutscene.ts`), 측정기 | |
| `world/` | 상태(`state.ts`), 박 시계·그루브, 판정, 노 젓기, 둘러본 기록 저장(`memory.ts`) | |
| `input/`, `audio/`, `ui/` | 마우스·키보드, 소리 합성, 화면 위 글자·메뉴 | |

### 잘 된 점
- 장면 하나 = 작은 상태 기계(들어옴·매 프레임·스트로크·박). 챕터가 늘어도 같은 틀
- **색의 약속(노란 빛·파란 빛)이 한 모듈(`counter.ts`)**이라 어느 챕터에서나 같은 판정
- 각 장면으로 바로 가기(`?step=`)와 그 장면까지의 상태를 맞춰 주는 `fastForward`가 있어 시험하기 쉬움

### 고칠 점 (급하지 않음, 순서대로 추천)
1. **`setTimeout` 타이머 27곳** (story): 메뉴로 일시정지해도 타이머는 흘러서, 멈춘 사이에 소리가 나거나 장면이 넘어갈 수 있다. 장면 시간(`el`)을 기준으로 하는 예약(`sceneKit`에 `after(초, 할 일)`)으로 바꾸면 해결
2. **`state.ts`의 상태 `S`가 한 덩어리**(약 150개 값): 챕터별로 묶어 두긴 했지만, 장면을 건너뛸 때 이전 챕터 값이 남는 일이 생길 수 있다. 챕터마다 '들어올 때 초기화할 값' 목록을 두는 정리 추천
3. **`draw.ts` 700줄**: 배·줄·악보 그리기를 각각 파일로 나누면 읽기 쉬워짐
4. 자동 테스트(`scratchpad/e2e`)는 저장소 밖에 있다. `tests/` 폴더로 옮겨 커밋하면 다음에도 쓸 수 있다 (원하시면)

## 4. 기믹 점검

### 챕터별 지도
| 챕터 | 처음 배우는 것 | 다시 쓰는 것 | 클라이맥스 |
| --- | --- | --- | --- |
| 0 안개 | 긁기·세기(pp/ff)·노 젓기·소나·코드 | — | 후렴 1 예고 |
| 1 고집의 섬 | 베이스 탐색, 둘러보기, 버티기 → 가시 뽑기 | 노·ff | C로 E♭ 가시 |
| 2 멈춘 시간 | 팜뮤트, 되받아 치기, 노란 빛(가드) | 둘러보기 | 떠다니는 피크 붙잡아 긁기 |
| 3 돛 | 파란 빛(카운터), 돛 게이지 → F 폭발 | 버티기 → 가시 | F로 A♭ 가시 + 받는 손 |
| 4 마른 바다 → 폭풍 | 자유 솔로, 격돌 ① | 노란·파란 빛 섞임 | D로 D♭ 가시 |
| 5 다시, 그 순간 | 보지 않을 때 다가오는 것, 시점 맞추기, 기억 테스트, 쉼표, 문장 바꾸기 | 되받아 치기, 둘러보기, pp | 진실 컷 · `나를 기억해 줘` |
| 6 깨어남 | (새 것 없음 = 마지막 관문) | 노란·파란 빛 반 박, F 폭발, 격돌 ②, pp | 함께 긁기 → 선택 → F |

### 좋은 흐름
- 새 기믹은 챕터당 1~2개(챕터 5만 예외: 이야기 챕터라 손이 바쁜 기믹이 아니라 '보는' 기믹들)
- 색의 약속이 챕터 2·3에서 배운 뒤 4·6에서 섞여 나온다
- pp(여리게)가 0의 속삭임 → 5의 기억 테스트·문장 바꾸기 → 6의 선택으로 **제목처럼 마지막 답이 된다**

### 확인이 필요한 점
- **챕터 5가 기믹이 가장 많다** (다섯 개). 각각 짧지만, 플레이해 보고 하나를 덜어 낼지 판단 필요 (후보: '우산을 든 쪽'은 손을 쉬는 장면이라 유지, '다가오는 것'과 '시점 맞추기' 중 하나)
- **쉼표(침묵)는 한 번만** 나온다. Toby 결정대로 '어울리는 챕터'에 더 쓰려면: 챕터 1의 1절(기타가 없는 시간)에 아주 짧은 맛보기, 챕터 6의 두 박동 장면
- **마지막 관문**은 시나리오의 '배운 기믹이 차례로'를 다 담지 못하고 노란·파란 빛 + F 폭발 + 칩 흐려짐 위주로 줄였다. 등불·되받아 치기·자유 솔로 한 마디씩을 더할지
- 격돌 ②에서 그 사람이 일어나는 타이밍(밀린 횟수/시간)이 자연스러운지

## 5. 시나리오 · 스토리 라인 점검

### 복선 → 회수 (모두 구현되었는지)
| 복선 (심은 곳) | 회수 (지금 구현) | 상태 |
| --- | --- | --- |
| 뻗은 손, 기타를 안고 깨어남 (0) | 진실 컷: 머리맡에서 기타를 치는 그 사람 (5) | ✔ |
| 모든 안내가 같은 붓글씨 (0~) | 그 사람의 손끝이 지난 안내를 다시 씀 + 핑크 실 (5) | ✔ |
| `나는 여기 있어` (0) | 진실 뒤 물 위에 다시, 그리고 `나를 기억해 줘` + 훅 가사 (5) | ✔ |
| 두 번째 심장 (0) | 두 박동, 하나가 느려짐 (6) | ✔ |
| 물그림자에 한 사람 (0) | ♮로 두 사람 (5) | ✔ |
| 천 조각 = 띠 색, 짧아지는 띠 (0~) | 돛 완성, 띠·겉옷이 사라짐 (3) | ✔ |
| 보지 않는 사이 바뀐 자세 (1) | 보지 않을 때 다가오는 기억 (5), 그 사람이 일어남 (6) | ✔ |
| 액자 밖의 그 사람 (1~2) | 그 사람 쪽에서 본 그림 (5), 기억 테스트 (5) | ✔ |
| 가시가 뱃머리로 (1~4) | 받는 손 (3), 물속에 빛나는 ♭ 셋 (5), 맡기면 마지막 가시도 (6) | ✔ |
| 손목의 금 (1) | 팔꿈치(3) → 어깨(4) → 온몸(5) | ✔ |
| ff가 지운 새 줄 (1) | 기억 테스트 2번에 답할 수 없음 (5) | ✔ |
| 1절의 기타 침묵 (1) | 엔딩 해설 (6) | ✔ |
| 세뇨 𝄋 (2) | D.S. 표지 (4) → 같은 순간으로 (5) | ✔ |
| 커서 피크의 ♭ (전체) | 엔딩 해설 '줄을 긁던 피크' (6) | ✔ (이번에 추가) |
| 원곡 반주(MR)로 바뀜 | 마지막 후렴에서 | ✘ 아직 (질문 18번) |
| 어린 나 (조력자 (나)) | 함께 긁기에 겹쳐 보이기 | ✘ 쓰지 않음 (선택 사항) |

### 이야기의 흐름에서 본 점
- **진실이 드러나는 순서가 좋다**: 다가오는 기억(그 사람은 늘 곁에) → ♮과 두 사람 → 붓글씨의 질문(내가 보지 않았던 것) → 침묵 속 진실 컷(잠든 건 나) → 내가 그 사람의 글을 고쳐 씀 → 깨어남
- **챕터 5 끝과 챕터 6 첫머리**: 진실을 본 뒤 다시 꿈의 바다로 돌아가는 이유가 화면에 `다시, 꿈의 바다` 한 줄뿐이다. "아직 깨어나지 않았다 = 이제 깨어나러 간다"가 더 분명하면 좋겠다 (예: 진실 컷의 머리맡에서 내 손가락이 아주 조금 움직이는 한 컷)
- **엔딩 '맡긴다'**: 그 사람이 마지막 가시도 삼키고 두 번째 심장이 아주 약해진 채 끝난다. 에필로그는 '기억이 흐려진 나'의 시점이라, 그 사람이 어떻게 되었는지는 일부러 말하지 않는다 (정의하지 않는다는 원칙). 의도대로인지 확인 필요
- **플레이 시간 45~50분**: 목표 60분보다 짧다. 늘린다면 이야기 장면(챕터 1의 섬, 챕터 5의 그림들)에 여운을 더하는 쪽이 기믹을 늘리는 것보다 낫다
