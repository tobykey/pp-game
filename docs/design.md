# pp — 게임 기획 노트

체리필터 '피아니시모'의 분위기와 정서를 따라가는 스토리 퍼즐 게임. 개인 프로젝트.
최종 갱신: 2026-10-18

---

## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 가제 | **pp** (피아니시모 기호). 부제 후보는 11장 참고 |
| 장르 | 스토리 퍼즐 + 항해 이동 + 리듬 기믹 |
| 핵심 경험 | 복선 회수 → 반전의 충격 → 감동 |
| 핵심 조작 | 왼손 키보드로 코드를 잡고, 오른손 마우스로 6현을 긁으면 파동이 퍼져 숨은 요소가 드러남 |
| 아트 톤 | 수묵화 베이스 + 락의 형광·판화 연출 ("먹과 형광") |
| 볼륨 | 몰입해서 하나씩 깨달아 가는, 볼륨 있는 게임 지향 (구체 플레이 시간 미정) |
| 저작권 | 원곡 음원·가사 사용은 추후 검토. 게임 안에 원곡 가사를 그대로 넣지 않는다 |
| 현재 단계 | 핵심 기믹 프로토타입 완료 → 챕터 0~1 버티컬 슬라이스 준비 |

플레이어는 이 곡이 바탕이라는 걸 알고 시작하지만, 숨겨진 복선을 풀며 같은 정서가 전혀 다른 의미로 뒤집히는 순간을 겪는다.

## 2. 원곡 분석 (악보 첫 부분 기준)

- **조성:** A♭ 장조 (플랫 4개), 4/4박자
- **특징:** 16비트 리듬의 댄서블함, 이모코어풍 리프, 5음계 위주의 동양적 선율, 브릿지 일렉 기타 솔로, 일렉 같은 보컬 음색

| 구간 | 코드 | 도수 | 느낌 |
| --- | --- | --- | --- |
| 인트로 (속삭임 훅 반복) | D♭ – A♭ | IV – I | 강하게 해결되지 않고 내려앉는 그리움 |
| 후렴 1회차 | D♭ – E♭ – Cm7 – D♭ | IV – V – iii7 – IV | 왕도진행 계열의 애틋함 |
| 후렴 2회차 | D♭ – E♭ – Cm7 – **F** | IV – V – iii7 – VI | F 장화음이 B♭m으로 끌어당기며 급격히 고조 |

- **왕도진행(IV–V–iii–vi 계열):** J-pop·애니 오프닝의 대표 진행. "애니 오프닝 같다"는 평의 화성적 근거.
- **F 장화음:** 조성에 원래 없는 코드(부속화음 V/ii). 게임에서 **"이 세계에 맞지 않는 존재"의 상징**으로 쓴다.
- 인트로 직후 바로 후렴으로 들어가는 구조라 첫인상에 진행이 바로 꽂힌다.

## 3. 스토리와 반전 구조 (확정)

반전의 축: **소중한 사람이 나의 아픈 기억을 대신 삼켜 왔다.**
목표: 1회차엔 "내가 그대에게" 하는 다짐으로 느껴지던 정서가, 진실을 안 뒤엔 "그대가 나에게" 하는 말로 뒤집혀 느껴지게 한다.

| | 플레이어가 믿는 이야기 (표면) | 실제 진실 (이면) |
| --- | --- | --- |
| 배경 | 안개 낀 바다, 작은 배 | 잠든 플레이어 자신의 기억 속 바다 |
| 뱃머리의 동행자 | 깨어나지 않는 사람. 내가 깨워야 할 사람 | 잠든 나를 지키러 꿈속에 들어온 사람 |
| 가시 | 내 심장의 가시를 뽑아 없앤다 | 뽑힌 가시는 사라지지 않고 그 사람이 대신 삼켜 왔다 |
| 반복되는 속삭임 | 내가 그 사람에게 하는 말 | 점점 희미해지는 그 사람의 목소리 |
| 기타 소리 (파동) | 내가 길을 밝히는 도구 | 처음부터 그 사람이 건넨 목소리 |

**엔딩 (확정: 2갈래)** — 마지막 가시 하나가 남는다.
- **내가 다시 품는다** → 아픔을 기억한 채 깨어나고, 그 사람도 곁에 있다
- **그 사람에게 맡긴다** → 아픔은 잊고 깨어나지만, 그 사람에 대한 기억도 흐려진다

## 4. 복선 배치

| 복선 | 처음 보일 때 | 회수 방법 |
| --- | --- | --- |
| 수면 반사에 사람이 한 명만 보임 | 안개 때문인 것처럼 연출 | 제자리표(♮) 아이템으로 '원래 모습' 확인 |
| 가시를 뽑을 때마다 동행자에게 금이 늘어남 | 작은 배경 디테일 | 마른 바다 챕터에서 금이 몸 전체로 번진 모습 |
| 돛 천이 동행자의 옷 색과 같음 | 그냥 예쁜 색 | 돛을 다 모으면 동행자가 입은 옷이 사라져 있음 |
| 기억의 섬마다 화면 가장자리에 반쯤 잘린 누군가 | 연출상 구도 | 기억 테스트에서 그 사람의 디테일을 물어봄 |
| 노 젓는 박자 = 심장 박동, 후반에 두 박동이 겹침 | 리듬 연출 | 하나가 점점 느려짐 → 엔딩 분기 |
| 시선을 돌리면 동행자의 자세가 바뀌어 있음 | 버그처럼 보이는 미세한 변화 | 사실 잠든 게 아니었다는 증거 |
| 세뇨(𝄋)로 같은 섬을 다시 방문 | 단순 되돌아가기 | 두 번째엔 같은 기억이 다른 각도로 보임 |

## 6. 기믹 시스템

모든 기믹은 **6현 스트럼** 하나의 조작 위에 얹는다. 세기·줄·주법·기호·편곡이 그 조작을 변주한다.
(잠정 원칙. 다른 악기도 등장시킬지와 함께 계속 검토 — 11장)

### 6-1. 6현 스트럼 소나 (핵심 조작)
화면 하단 6현을 드래그해 긁으면 그 지점에서 파동이 퍼지며 숨은 섬·글씨·길이 드러난다. (소나 = 음파 탐지기에서 따온 임시 이름)
- **줄별 파동:** 굵은 6번 줄은 멀리 퍼지지만 윤곽만, 가는 1번 줄은 가까이만 닿지만 세밀한 디테일까지
- **스트럼 방향:** 다운/업에 따라 파동 시작 위치·방향이 달라짐
- **공명:** 특정 음에 맞춰진 등대·종·부표가 해당 줄/코드에 반응해 떨림
- **화음 간섭:** 여러 줄의 파동이 겹치는 곳에 비밀
- **주법:** 벤딩(파동을 휘어 해류 너머 탐색), 하모닉스(투명한 것만 보임), 팜뮤트(짧게 끊어 근거리 정밀 탐색)

### 6-2. 양손 연주 조작
실제 기타처럼 **왼손은 키보드로 코드를 잡고, 오른손은 마우스로 스트로크**.
- 키 조합 배치가 실제 운지 모양과 닮게 설계 (초안: C = Q+S+C, D = S+Z+C)
- 마우스 위→아래 다운, 아래→위 업, 천천히 긁으면 아르페지오. 빠를수록 세게
- **평소에도 자유 연주:** 점프 연타처럼 이동 중에도 습관처럼 칠 수 있게. 그 습관을 퍼즐로 역이용하는 것도 고려
- 검토: 키보드 행·열을 줄·프렛에 대응시키는 일관 규칙, 모바일(키보드 없음) 대응

### 6-3. 맵별 편곡 변주
같은 코드도 **장소에 따라 다른 주법·음색**으로 울린다.

| 편곡 | 어울리는 장소 (초안) |
| --- | --- |
| 원곡 락 (일렉 디스토션) | 폭풍, 클라이맥스, ff 구간 |
| 어쿠스틱 기타 | 평온한 섬, 기억 회상 |
| 신스 스트링·현악 오케스트라 | 돛을 펴는 장면, 반전 직후 |
| 한국풍 (가야금·해금 등) | 안개 낀 바다, 수묵 색이 가장 짙은 맵 |

### 6-4. 셈여림·악상 기호 (피아니시모)

| 기호 | 역할 |
| --- | --- |
| ff | 안개를 걷고 장애물을 부숨. 연약한 기억 조각까지 흩어짐 |
| pp | 아무것도 부수지 못하지만, 이 세기에서만 보이고 들리는 것이 있음 |
| 크레셴도 / 디크레셴도 | 쐐기 모양 수로. 점점 세게/여리게 연주하며 통과 |
| 페르마타 (𝄐) | 시간 정지 |
| 세뇨 (𝄋) / 코다 | 워프 포인트. 같은 기억을 다시 보게 해 복선 회수 |
| 제자리표 (♮) | 위장된 것을 원래 모습으로 되돌리는 아이템 (실제 악보 F 코드 마디에 등장) |

**반전 장치:** 게임 내내 세게 긁어 길을 여는 데 익숙해지지만, 진실은 오직 pp로만 드러난다. 제목 자체가 마지막 퍼즐의 정답.

### 6-5. 코드 글자 기믹
- D♭ – E♭ – Cm7 – F 글자가 섬 이름·좌표·문 암호로 등장
- **조표의 플랫 4개(B♭, E♭, A♭, D♭) = 심장의 가시 4개.** 하나 뽑을 때마다 조표에서 플랫이 사라짐
- Cm7의 7: 일곱 번째 섬, 7번째 박에서만 열리는 문 등 숫자 단서
- **화음 등대 퍼즐:** 마지막 관문은 조성에 맞지 않는 F 장화음으로만 열림

### 6-6. 기타 솔로 · 보컬
- **브릿지 기타 솔로 = 마른 바다 챕터:** 정답 없이 6현을 자유롭게 긁고 벤딩하며 길을 그림. 유일하게 '표현'하는 구간
- **보컬 = 기타 음색:** 속삭임을 기타 피드백처럼 처리. 진실이 드러날 때, 내내 긁어온 기타 소리가 그 사람의 목소리였음을 깨닫게 함

### 6-7. 노 젓기 리듬
16비트 리듬에 맞춰 좌/우 노. 박자를 놓치면 해류에 밀림. 후반에 박동이 둘로 갈라질 때 어느 박자를 따르느냐가 엔딩에 영향.
- **조작 (잠정, 2026-10-18):** 노 젓기 = 스트로크. 다운 스트로크는 왼쪽 노, 업 스트로크는 오른쪽 노. 박자에 맞춰 다운·업을 번갈아 긁으면 배가 나아간다. 일단 이 방식으로 구현하고, 플레이해 보며 다듬는다

### 6-9. 항해 이동 (확정, 2026-10-18)
**가로 스크롤.** 프로토타입의 옆에서 본 구도(수평선·배·아래 6현)를 유지한 채, 배가 좌우로 나아가며 섬과 섬 사이를 항해한다.

### 6-10. 템포 설계 (확정, 2026-10-18)
원곡은 **130 BPM**. 장면과 기믹마다 템포 단계를 정해 긴장도를 조절한다.

| 단계 | 언제 | 템포 |
| --- | --- | --- |
| 느림 | 초반 구간, 차분한 스토리 진행 | 130보다 느리게 (구체 값은 장면별로 정함) |
| 원곡 | 주요 기믹, 중요한 장면 | 130 |
| 극한 | 최후반 마지막 구간 | 130보다 훨씬 빠르게 |

**최후반 클라이맥스 구상:**
- 사람이 따라갈 수 없을 만큼 템포가 빨라지고, 화면이 몹시 크게 흔들리며, 파훼할 수 없을 만큼 패턴이 쏟아진다
- 플레이어가 포기하거나 감당하지 못할 지경, 긴장과 몰입이 최고조에 이르러 좌절하기 직전까지 몰아붙인다
- 그 순간 스토리 속 조력자가 돕고, 지금까지 발견해 온 복선과 기믹이 가세해 하나씩 파훼해 나간다
- 목표: 아주 진한 감동과 여운
- 주의: `prefers-reduced-motion`(동작 줄이기) 설정에서는 흔들림·섬광을 줄이되, 압도감은 템포와 패턴 밀도로 유지한다

### 6-8. 기억 테스트
마른 바다 챕터에서 동행자가 처음 입을 열어, 앞선 섬들에 반쯤 잘려 있던 자신의 디테일을 묻는다. 제대로 보지 않은 플레이어는 답하지 못하고, 그 자체가 감정적 충격이 된다.

## 7. 아트 디렉션: 먹과 형광

평소엔 **먹 90% · 형광 10%**. 수묵화로 피아니시모를, 형광·판화 질감으로 락을 표현하고, 클라이맥스에서만 형광이 화면을 덮는다.

- **참고 톤:** 앨범 커버의 형광 핫핑크 배경, 굵은 검정 외곽선과 평면 채색, 원색 포인트, 붓 손글씨 로고. "어두운 존재가 빛나는 것을 끌어안는" 구도만 키 비주얼 모티프로 차용하고, 캐릭터·디자인은 모두 오리지널로 만든다
- **연결 고리 — 낙관(落款):** 수묵화의 붉은 인장 자리를 핫핑크로 바꿔 수묵 문법 안에 락의 정체성을 넣는다

| 상태 | 표현 |
| --- | --- |
| 평온 (pp) | 한지 질감, 먹의 농담, 넓은 여백. 안개는 번지기, 파도는 갈필. 색은 작은 핑크 낙관 정도 |
| 고조 (ff) | 먹이 사방으로 튀는 스플래시, 핑크·노랑 섬광, 판화풍 굵은 외곽선, 집중선, 화면 흔들림 |

## 8. 프로토타입 현황 (`prototype/pp-prototype.html`)

브라우저에서 바로 열리는 단일 HTML. 챕터 0 '안개'의 씨앗.
2026-10-17: 같은 동작 그대로 Vite + TypeScript(`src/`)로 이식. 원본 HTML은 손맛 기준으로 보존한다.

구현됨:
- 6현 드래그 스트럼 (다운·업·아르페지오), 긁는 속도 → 세기(pp~ff)
- 왼손 키 코드: D♭(A S D), E♭(W E R), Cm7(Z X C V), F(Q A Z, 조성 밖이라 핑크 표시), A♭(W S X), C(Q S C), D(S Z C). 터치에선 칩 눌러 고정. Shift = 팜뮤트
- 줄별 파동 거리/디테일 차이, ff 연출(먹 스플래시·섬광·집중선·화면 흔들림), pp에서만 보이는 문장
- 편곡 4종 음색 (1~4 키): 락(디스토션), 어쿠스틱, 현악(신스), 국악(농현). Web Audio로 합성
- 퍼즐: 안개 속 등불 4개를 찾아 D♭ → E♭ → Cm7 → F 순서로 울림. 점등마다 조표 플랫(가시) 하나씩 제거, 완성 시 돛 펼침 연출
- 복선: 가는 줄로 배 아래를 비추면 수면 반사에 한 사람만 보임
