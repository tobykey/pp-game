# 기믹 도감 (2026-10-19)

Toby의 제안: 로스트아크 같은 게임의 다양한 기믹(구슬 기억, 장판, 카운터, 가드, 아재 패턴, 무력화, 격돌)을 차용해 감동과 긴장을 준다.
원칙: **그대로 가져오지 않고 6현과 곡의 언어로 번역한다.**

## 0. Toby 결정 (2026-10-19)
- **채택:** 되받아 치기, 공명 카운터, 팜뮤트 가드, 버티기 → 뽑기(무력화 → 딜), **격돌 (아주 마음에 듦)**, F 폭발, 보지 않을 때 다가오는 것
- **빼기:** 장판 피하기(안전한 물 찾기)
- **보류:** 아재 패턴(코드 행진) — 잘 모르겠음. 챕터 6을 짤 때 다시 본다
- **이야기를 볼 틈 원칙: 채택**

## 1. 차용 기믹 (번역안)

| 원본 (로스트아크 등) | pp 기믹 | 조작 | 의미 | 배치 |
| --- | --- | --- | --- | --- |
| 색깔 구슬 기억 | **되받아 치기** — 꿈이 코드 몇 개를 들려주면(등불·빗방울이 차례로 빛남) 같은 순서로 되받아 친다 | 코드 + 스트로크 | 그 사람이 건넨 소리를 따라 하기 | 2, 5 |
| 장판 피하기 | **안전한 물 찾기** — 먹 파도가 덮치기 전, 소나로 비춰야 잔잔한 물길이 보인다 | 소나 + 노 | 폭풍 속에서도 길은 소리로만 보인다 | 4 |
| 카운터 (파란 빛) | **공명 카운터** — 파란 빛이 정박에 "짠!" 하고 나타나면 **다음 박**에 그 마디 코드로 아주 세게(ff) 받아친다. 뒤로 갈수록 **반 박 전에** 나타나 빠르게 대처 (2026-10-20 Toby 결정) | 타이밍, 세기 | | 3, 6 |
| 가드 (노란 빛, G) | **팜뮤트 가드** — 노란 빛이 덮칠 때 Shift를 누른 채 긁어 소리를 죽이면 막힌다 | Shift + 스트로크 | 팜뮤트 = 소리를 막는 주법 | 2에서 배움, 4·6 |
| 아재 패턴 (제한 시간 안에 키 전부) | **코드 행진** — 제한된 마디 안에 곡의 진행을 쭉 쳐 낸다 | 연속 코드 | | 6 |
| 무력화 → 딜 | **버티기 → 뽑기** — 게이지를 채우면 잠깐 열리는 틈에 결정 코드 | 박 + 결정 코드 | 가시 뽑기의 기본형 (챕터 1 구현) | 가시마다 변주 |
| 격돌 | **줄다리기 격돌** — 정해진 시간 동안 빠르게 긁어 밀어낸다 | 연타 스트로크 | 폭주 스트로크(6-11)와 같은 결 | 4 ①, 6 ② (그 사람과 함께) |
| 파타퐁 (구령) | **네 박 구령** — 정해진 네 코드로 배를 지휘 (예: D♭ D♭ E♭ A♭ = 전진) | 코드 4개 | | 후보 |
| 기타 히어로 스타 파워 | **F 폭발** — 연속으로 딱 맞추면 게이지가 차고, F를 치면 형광 폭발 | 연속 판정 + F | F = 그 사람 | 3 |
| 부끄부끄 (보지 않을 때 움직임) | **보지 않을 때 다가오는 것** — 둘러보기와 자세 변화 복선을 퍼즐로 | ← → 둘러보기 | 잠든 게 아니었다 | 5 |

## 2. 이야기를 볼 틈 (Toby 피드백: 6현을 튕기느라 스토리를 볼 정신이 없다)

1. **차분한 구간 = 이야기**: 손이 쉬는 동안(노만 젓거나 배가 저절로 흐를 때) 기억 그림·붓글씨·복선을 보여 준다
2. **기믹 구간 = 긴장**: 글자를 띄우지 않는다. 이야기는 그림과 소리로만
3. **기믹 뒤엔 반드시 여운**: 손을 놓게 하는 시간
4. **새 기믹은 챕터당 1~2개**, 앞에서 배운 것을 섞어 쓴다
