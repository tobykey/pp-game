# 개발 일지 — pp

체리필터 「피아니시모」에서 출발한 웹 스토리 퍼즐 게임 **pp**를 날짜별로 정리한다.
**언제, 무엇을 정하고, 무엇을 만들었는지** 한 파일에서 볼 수 있게 한다. 자세한 근거는 `docs/design.md`(기획 전체)와 각 시나리오 문서에 있다.

- 기획: Toby (Claude 앱에서 기획을 다듬고, 원본은 `docs/design.md`)
- 구현: Claude Code와 함께 (TypeScript + Vite, 캔버스, Web Audio)
- 버전: 프로토타입 v0.1(단일 HTML) → v0.2(챕터 0) → v0.3(챕터 1) → v0.4(챕터 2) → v0.5(챕터 3) → v0.6(챕터 4)

## 2026-10-18 (토) — 곡이 곧 챕터

**정한 것**
- 이동 방식: **가로 스크롤 항해** (옆에서 본 구도 그대로 배가 섬 사이를 나아감)
- 템포 3단계: 느림 65(원곡의 절반) · 원곡 130 · 극한(최후반)
- 노 젓기 = 스트로크 (다운 = 왼쪽 노, 업 = 오른쪽 노, 박에 맞춰 번갈아)
- **챕터를 실제 곡 연주 순서로 재구성**: 0 도입·훅·후렴 1 → 1 간주·1절 → 2 프리코러스 → 3 후렴 2 → 4 훅·랩·리프 → 5 프리코러스 D.S. → 6 후렴 3·코다
- 저작권: 지금은 개인 취미·팬메이드 단계라 제약 없이 진행, 공개 전 원작자에게 문의 (원본 MR·악보는 저장소에 올리지 않음)

**만든 것**
- `docs/song-map.md`: 악보와 MR을 마디 단위로 분석한 곡 구성표 (후렴이 한 번도 으뜸화음에 닿지 않는다는 발견 등)
- 챕터 0~1 장면 시나리오 (v0.2 → v0.3)
- **챕터 0 '안개' 처음부터 끝까지 플레이 가능 (v0.2)**: 눈뜸 → 속삭임 → 노 젓기 → 등불 → 훅 → 물그림자 → 천 조각 → 후렴 1 예고 → 섬
- 박 판정에 소리 출력 지연 보정
- **챕터 1 '고집의 섬' (v0.3)**: 간주 항해 → 줄이 끊어짐(1절엔 기타가 없다) → 베이스로 탐색 → 밤의 방·빈 무대 → 첫 가시(C로 E♭을 뽑음) → 비 → 여운

**플레이 피드백으로 고친 것**
- 화면 깜빡임(광과민성 위험) — 원본부터 있던 안개 순간이동 버그를 찾아 고침. 이후 모든 큰 연출은 번쩍임을 측정해서 넣음
- 6현 음량 게이지, 커서는 평소 붓끝 · 긁을 때 피크
- 둘러보기는 드래그 대신 ← → 방향키, 가시 클라이맥스를 더 극적으로, 바위는 바위 위치에서 부서지게, 비의 섬은 쉽게

## 2026-10-19 (일) — 이야기의 뼈대

**정한 것 (Toby의 답 12가지)**
- 그 사람은 **정의하지 않는다** · 얼굴도 보여 주지 않는다 · **말하지 않는다** (붓글씨와 몸짓으로만)
- 나는 왜 잠들어 있나 → **"머리맡의 연주"**: 그 사람이 현실에서 내 머리맡에서 이 노래를 연주해 왔다
- 천 조각 6개 = **희망의 돛** (기타 여섯 줄, 내가 거절했던 도움이 조각이 되어 돌아옴)
- 가시 배치: E♭(1) · A♭(3) · D♭(4) · 마지막에 남는 B♭ · 엔딩은 두 선택지를 분명하게
- 최후반 조력자 = 그 사람 자신 · 폭주 스트로크 ① = 챕터 4 · 원곡 가사 사용 · 전체 60분 안팎
- **기믹 도감**: 로스트아크 등에서 차용해 6현의 언어로 번역 (되받아 치기, 공명 카운터, 팜뮤트 가드, 버티기 → 뽑기, 격돌, F 폭발). 장판 피하기는 빼고, 코드 행진은 보류
- **이야기를 볼 틈 원칙**: 차분한 구간에 이야기, 기믹 구간엔 글자 없이, 기믹 뒤엔 반드시 여운

**만든 것**
- 전반 검토 보고서 (`review-2026-10-19.md`): 유명 리듬·이야기 게임과 비교
- 다음 코드 미리보기, 박 접근 원과 판정 먹 도장, Esc 메뉴(일시정지·음량·박 보정·흔들림 줄이기·장면 고르기), 박과 심장 박동 표시 강조 (v0.3.1)
- `synopsis-ch2-6.md`(챕터 2~6 줄거리), `gimmicks.md`(기믹 도감), 챕터 2 시나리오

**플레이 피드백으로 고친 것 (v0.5.1)**
- 가시를 뽑을 땐 화면 가득 **`가시 뽑기` + 코드 + 키 + 치는 법**
- 뽑으면 **가시 뽑기 컷신**: 게임 위에 한지 판이 덮이고 박힌 ♭ → ♮이 내리꽂힘 → ♭이 솟구침 → `가시 뽑기 성공`. 챕터 3은 이어서 **받는 손** 컷 (손목에서 팔로 번지는 금)
- 카운터는 옆에서 밀려오지 않고 **정박에 '짠!' 나타나 다음 박에 받아치기**. 뒤로 갈수록 반 박 전에 나타남 (Toby: "이제야 카운터를 하는 것 같다")
- 하얀 빛을 더 길게, 돛 게이지에 뜻을 붙임, **F 폭발**을 히트스톱 · 화면 당김 · 화면 가득 붓글씨 F · 형광 번짐으로
- 뽑는 장면을 더 천천히 (코드 소리를 ♮이 박히는 순간에 맞춤)

## 2026-10-21 (화) 낮 — 챕터 5

## 2026-10-21 (화) 밤샘 ① — 챕터 5 피드백과 최적화

**정한 것 (Toby 피드백)**
- 다가오는 것·시점 맞추기 좋음. 기억 테스트 렉, 무채색 답 그림, 침묵·자리 바뀜이 약함, 문장 고쳐 쓰기의 "아!"가 약함 → 고침
- 프레임이 떨어지는 무거운 연출은 피한다

**만든 것 · 고친 것**
- 그리기 부하 측정기를 만들어 구간별로 재 봄 → 렉 원인은 답 그림의 흐림 필터(프레임당 38.7ms) → 없애고 8.7ms
- 안개·비네트를 1/4 해상도로, 1절 색 빠짐은 줄 위쪽만 → 모든 장면이 가벼워짐
- 기억 테스트: 흐릿한 까닭을 글로, 확인용 `?seen`
- 침묵의 긴장(어두워지는 가장자리, 조여 드는 화면, 커지는 두 번째 심장, 박 점) → **진실 컷**: 꿈 바깥의 머리맡 `잠든 건, 나였다`
- 문장 고쳐 쓰기 전에 지난 안내들을 그 사람의 손끝이 다시 씀 + 뱃머리에서 이어진 핑크 실
