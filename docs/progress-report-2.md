### 챕터 2 · 멈춘 시간 (시나리오 docs/scenario-ch2.md 그대로)
| 장면 | 하는 일 |
| --- | --- |
| 멈춘 비 | 비가 공중에 멈춰 있고 하늘에 페르마타(𝄐). 보통으로 긁으면 소리가 뭉개지고, **Shift(팜뮤트)로 짧게** 쳐야 또렷하다. 가까이 퍼지는 파동이 지나가면 빗방울이 노랗게 울린다 |
| 빗방울 되받아 치기 | 빗방울 기둥이 코드를 차례로 빛내며 들려준다(그 사람의 기타 소리) → **같은 순서로 Shift + 코드**로 되받아 치면 기둥이 녹는다. 2개 → 3개 → 4개(D♭ E♭ Cm D♭). '다음' 미리보기 켜 둠. 틀리면 다시 들려준다 |
| 우산 아래 | 손을 쉬는 이야기 장면. 첫 만남의 기억: 걷던 나에게 뒤에서 **핑크 우산**이 씌워지고, 내가 고개를 든다. 얼굴은 보이지 않는다. 가사 "그대를 만난 순간"이 번진다. **조각 4**, 액자 모서리에 **세뇨(𝄋)**. ← 키로 둘러본 사람만 액자 밖 **먼저 와서 기다리던 발자국** |
| 쏟아지는 비 | 시간이 풀리며 130 BPM. 프리코러스 그루브(16분 하이햇). **노랗게 빛나는 빗줄기**가 박에 맞춰 덮쳐 온다 → 박 안내 원이 노랗게 되면 **Shift + 스트로크로 막기**(배 위에 핑크 우산 모양이 펴짐). 그 사이엔 노를 젓는다 |
| Csus4 → C | 비가 다시 멈추고 세상이 어두워짐, 큰 **C** 안내 → C로 풀고 → **여섯 줄을 아주 천천히 길게** 긁으면 피크 스크래치 소리와 함께 후렴(D♭)으로 터진다 → 챕터 3 제목 카드 |

### 고친 것
- **'둘러본 사람만' 규칙의 구멍**: 배가 그림에 다가가는 동안 액자 밖 디테일이 저절로 화면을 지나가며 보여 버렸다 → 이제 **← → 키로 둘러보는 동안에만** 드러난다 (챕터 1 그림들 포함). 테스트로 확인: 둘러보지 않으면 안 보이고, 둘러보면 보인다
- 챕터 2에 들어오면 챕터 1 그림을 거둔다 (비의 섬 '우산을 든 사람'이 챕터 2의 반전을 미리 보여 주지 않게)
- Csus4 장면에서 C를 치는 손동작이 '길게 긁기'로 잘못 판정되던 것

## 3. 검증

  - 챕터 2: 되받아 치기 3기둥, 노란 빗줄기 5개 모두 막음(BBBBB), C → 천천히 긁기 → 챕터 2 끝
- 메뉴 일시정지, 깜빡임 측정(쏟아지는 비 장면 포함) 정상
- 타입 검사·빌드 통과

## 4. 확인해 주실 것 (체험 순서)
1. **챕터 1의 조각 연출**: 담요·우산이 날아오고, 새 줄이 불타는 것이 눈에 들어오는지
2. **멈춘 비**: 팜뮤트로만 또렷한 느낌, 빗방울이 울리는 느낌
3. **되받아 치기**: 들려주는 소리를 듣고 따라 치는 게 재미있는지, 난이도
4. **우산 아래**: 손을 쉬고 이야기를 보는 틈이 충분한지 (← 키로 액자 밖도 둘러보세요)
5. **팜뮤트 가드**: 노란 원 → Shift + 스트로크가 직관적인지
6. **마지막 '아주 천천히 길게'**: 느낌이 사는지

## 5. 챕터 3 '돛' 시나리오 초안 (docs/scenario-ch3.md, 검토 대기)
후렴 2 · 130 · 첫 형광 클라이맥스. 새 기믹 **공명 카운터**(물든 코드로 파도 되받아치기)와 **F 폭발**(돛의 조각이 하나씩 형광으로 빛나 게이지가 되고, F 마디에서 폭발). 조각 5·6은 하얗게 가려진 사이 그 사람이 옷을 풀어 채우고, 마지막 F의 문에서 A♭ 가시를 뽑을 때 그 사람의 손이 아주 조금 움직여 받는다. 문서 끝에 정해 주실 것 5가지.
