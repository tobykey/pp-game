# 전반 검토: 인기 게임과 비교한 진행·조작·연출·화면 (2026-10-19)

프로토타입 v0.3(챕터 0~1)을 기준으로 검토했다. "부족한 것은 채우고, 과한 것은 덜어낸다."

## 1. 비교 대상과 배울 점

| 게임 | 성격 | 배울 점 |
| --- | --- | --- |
| 리듬 세상 (Rhythm Heaven) | 리듬 | 박을 **미리 보여 주는** 신호(예비 동작), 성공·실패를 소리와 몸짓으로 즉시 알려 줌, 실패해도 웃으며 다시 |
| 오수 (osu!) | 리듬 | 다가오는 원(접근 원)으로 박을 눈으로 예측, **입력 지연 보정** 설정은 리듬 게임의 기본 |
| 사요나라 와일드 하츠 | 음악 서사 | 곡 = 챕터, **실패 없이 흐르는** 진행, 장 시작마다 제목 카드, 짧은 재시도 |
| 하이파이 러시 | 리듬 액션 | 세상 전체가 박에 맞춰 움직임, 판정 피드백이 화려하지만 **화면 글자는 적음** |
| 썸퍼 | 리듬 | 긴장이 오를수록 카메라·속도·소리가 함께 조여 옴 → 이번에 기획한 '폭주 스트로크'의 참고 |
| 그리스 (GRIS) | 감성 서사 | **글자 없는 화면**, 조작이 곧 감정, UI는 필요할 때만 나타났다 사라짐 |
| 저니 (Journey) | 감성 서사 | 화면에 거의 아무것도 없음, 동행자의 정체가 끝까지 여운 |
| 플로렌스 (Florence) | 감성 서사 | 단순한 조작이 그 장면의 감정을 그대로 흉내 냄, 장마다 짧은 제목 |
| 셀레스트 (Celeste) | 퍼즐·플랫폼 | 가르치기 → 시험 → 비틀기 순서, **도움 모드**(어려우면 판정을 너그럽게)를 부끄럽지 않게 제공 |
| 스피릿페어러 | 감성 서사 | 배 위에서의 동행, 일시정지 메뉴에 편의 설정이 잘 정리됨 |

## 2. 지금 버전에 부족한 것 → 이번에 채움

| # | 부족한 점 | 근거 (일반적인 방식) | 반영 |
| --- | --- | --- | --- |
| 1 | **다음에 칠 코드를 미리 알 수 없다** (Toby 요청) | 리듬 게임은 다음 입력을 항상 미리 보여 준다 | 코드 도장 위에 `다음` 미리보기. 마디가 바뀌기 직전 반짝 |
| 2 | **박이 언제 오는지 미리 볼 수 없다.** 작은 박 점뿐 | osu의 접근 원, 리듬 세상의 예비 동작 | 코드 도장 둘레에 **접근 원**: 박 직전에 줄어들어 박에 딱 맞게 닫힘 |
| 3 | **잘 쳤는지 알 수 없다** | 리듬 게임의 판정 피드백 | 먹 도장으로 판정 표시: 딱 맞음 ◎ · 맞음 ○ · 놓침 번짐. 글자 없이 |
| 4 | **일시정지·설정이 없다** | 거의 모든 게임의 기본 | **Esc 메뉴**: 계속하기, 전체·6현 음량, 박 보정, 흔들림·섬광 줄이기, 음색, 장면 고르기, 처음부터(확인 후) |
| 5 | **입력 지연 보정이 없다.** 기기마다 박이 어긋날 수 있음 | 리듬 게임 필수 설정 | 메뉴의 `박 보정` (−120~+120ms) |
| 6 | **어려우면 계속 어렵다** | 셀레스트의 도움 모드, 많은 리듬 게임의 적응형 판정 | 연속으로 놓치면 판정을 조금씩 너그럽게 (맞추면 원래대로). 화면엔 알리지 않음 |
| 7 | **장이 시작되는 느낌이 약하다** | 사요나라·플로렌스의 제목 카드 | 장 시작에 **제목 카드** (붓글씨 제목 + 곡 구간) |
| 8 | 흔들림·섬광을 운영체제 설정으로만 줄일 수 있다 | 접근성 기본 | 메뉴에서 직접 켜고 끔 (광과민성 대비) |

## 3. 과한 것 → 이번에 덜어냄

| # | 과한 점 | 반영 |
| --- | --- | --- |
| 1 | **화면 위 버튼이 많다** (음색 4개, 처음부터, 음량) — 감성 게임치고 계기판 같다 | 음색·처음부터를 메뉴로 옮김. 위에는 6현 음량과 메뉴 버튼만 |
| 2 | **아래 조작 안내 줄이 늘 떠 있다** | 처음 몇 분만 보이고 사라짐. 메뉴의 '조작법'에서 다시 볼 수 있음 |
| 3 | **목표 문구가 늘 진하게 떠 있다** | 바뀔 때만 진하게, 몇 초 뒤 옅어짐 |
| 4 | **글자 채널이 너무 많다** (목표·진행·배너·붓글씨 안내·큰 안내 5가지가 동시에) | 역할을 나눔: 목표(위, 옅게) · 붓글씨 안내(가르칠 때만) · 큰 안내(꼭 해야 할 때만) · 배너(사건만). 이벤트 배너 일부를 그림 연출로 대체 |

## 4. 지금이 좋은 것 (유지)

- 실패 없이 흐르는 구조 (사요나라 방식)
- 곡 = 챕터, 퍼즐 코드 = 곡의 코드 (핵심 가치)
- 조작이 감정을 흉내 냄: 줄이 끊어지면 베이스로, 세게 치면 흩어짐 (플로렌스·그리스 방식)
- 둘러보는 사람만 보이는 액자 밖의 그 사람 (저니식 여운)
- 가르치기 → 시험 순서 (챕터 0 튜토리얼)

## 5. 이번엔 기록만 하는 것 (다음 단계 후보)

- **폭주 스트로크** (Toby 기획, design.md 6-11): 썸퍼처럼 카메라가 다가오고 심장·박이 한계까지 빨라져 쉴 새 없이 긁는 기믹. 두 번 등장하고, 두 번째에서 조력자가 나타나 복선을 회수하며 엔딩으로 향한다
- **숙련되면 코드 칩이 사라지는 연출** (ideas.md)
- 화면 UI를 세계 안으로 넣기 (운지표를 기타 목에, 조표를 돛에 등) — 그리스·저니식, 아트 단계에서
- 캐릭터·배경 정식 아트, MR 사용

## 6. 반영 결과와 검증 (2026-10-19)

| 항목 | 상태 |
| --- | --- |
| 다음 코드 미리보기 | 반영. 후렴 예고·간주는 다음 마디, 훅·부표·가시는 다음에 칠 코드, 비의 섬은 그다음 마디 |
| 접근 원 | 반영. 코드 도장 둘레 원이 박에 맞춰 닫힘 |
| 판정 먹 도장 | 반영. ◎ 딱 맞음 · ○ 맞음 · 번짐 놓침 |
| Esc 메뉴 | 반영. 멈추면 박 시계와 소리가 함께 멈췄다 이어짐 (자동 테스트로 시간 정지 확인) |
| 박 보정 | 반영 (−120~+120ms, 브라우저에 기억) |
| 도움 판정 | 반영. 연속으로 놓칠 때마다 판정 범위가 15%씩 넓어짐 (최대 60%), 맞추면 원래대로 |
| 장 제목 카드 | 반영 (챕터 0, 챕터 1 시작) |
| 흔들림·섬광 줄이기 직접 설정 | 반영 |
| 위쪽 버튼 정리 | 반영. 6현 음량 + 메뉴만. 음색·처음부터(두 번 눌러 확인)는 메뉴로 |
| 아래 조작 안내 | 반영. 등불 찾기부터 사라짐, 메뉴에서 늘 보이게 가능 |
| 목표 문구 | 반영. 바뀔 때만 진하고 6초 뒤 옅어짐 |
| 이벤트 배너 줄이기 | 일부 반영 (바위 '부서졌다' 배너 제거) |

검증: 챕터 0·1 전체 자동 플레이 통과, 콘솔 오류 없음, 깜빡임 측정 정상, 타입 검사·빌드 통과.
