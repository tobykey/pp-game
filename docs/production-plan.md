# 본 제작 전환 계획 — 프로토타입에서 '공개할 수 있는 게임'으로 (2026-10-23)

지금까지는 **전체 흐름을 처음부터 끝까지 만들어 보는 프로토타입** 단계였다 (챕터 0~6, 두 엔딩, 원곡 클라이맥스, 큰 기믹의 되감기).
이제 **퀄리티를 공개할 수준으로 끌어올리는 본 제작**으로 넘어간다. 이 문서는 그 전에 짚어야 할 것, 오래 걸리는 작업, 정해야 할 것을 모은다.

## 2. 그림을 어떻게 '진짜 그림'으로 바꿀까 (가장 중요한 결정)

### 세 가지 길
| 길 | 방법 | 장점 | 단점 |
| --- | --- | --- | --- |
| **A. 코드로 그린 수묵 (지금 시작함)** | 붓 도구를 코드로 만들어(번짐·마른 붓·한지 결) 미리 그려 두고 붙인다 | 저작권 걱정 없음, 화면 크기에 맞춰 선명, 가볍다, 지금 바로 계속할 수 있다 | 사람이 그린 그림의 '손맛'과 표정에는 한계. 캐릭터 연기에 약하다 |
| **B. 그림 작가에게 의뢰** | 수묵·일러스트 작가에게 목록을 주고 그림(투명 배경 PNG/WebP)을 받는다 | 가장 높은 퀄리티, 이 게임만의 얼굴 | 비용·시간. 팬메이드라 의뢰 조건(공개 범위, 비영리)을 분명히 해야 함 |
| **C. Toby가 직접 그리기 / 생성 도구로 초안** | Toby의 그림 또는 이미지 생성 도구로 초안을 만들고 다듬는다 | 방향을 빨리 볼 수 있다 | 생성 도구는 스타일 일관성·저작권 정책 확인 필요. 무료 소스 그림은 수묵 스타일이 드물다 |

### 추천: **A + B (또는 C) 섞기**
- **배경·물·하늘·효과·파동·붓글씨 연출 = A (코드 수묵)**. 오늘 밤 시작한 방식으로 계속. 넓고 움직이는 것은 코드가 더 낫다
- **캐릭터 · 기억 그림 다섯 장 · 컷신 판 · 제목 키 비주얼 = B 또는 C**. 표정과 손짓이 이야기를 끌고 가는 것들
- 그림이 들어올 자리는 코드에 미리 만들어 두면(아래 목록의 크기·투명 배경), 그림만 바꿔 끼우면 된다

### 그림이 필요한 목록 (사람이 그려야 빛나는 것)
| 무엇 | 장수 | 크기·형식 (권장) | 쓰는 곳 |
| --- | --- | --- | --- |
| 나 (기타를 안고 앉음): 기본 · 노 젓기 둘 · 누움 | 4 | 512×512 투명 PNG | 배 위, 물그림자 |

| 기억 그림: 밤의 방 · 빈 무대 · 비 · 첫 만남 (각각 내 쪽 / 그 사람 쪽) | 8 | 1600×420 | 챕터 1·2·5 |

## 3. 본 제작 전에 정해야 할 것 (Toby)
1. **그림의 길**: A만 / A+B / A+C
2. **캐릭터 디자인**: 나와 그 사람의 실루엣·옷·머리 (얼굴은 그 사람만 끝까지 안 보임 — 나는?)
3. **플랫폼**: PC 브라우저만 / 휴대폰(터치)까지
4. **오른손 세기·키 배치**: 지금 방식 유지 / 바꿈 (10-19부터 미결)
5. **목표 플레이 시간**: 지금 약 45~50분. 60분으로 늘릴지
6. **공개 시점과 원작자 문의 시점**

## 4. 본 제작 순서 (안)
1. **아트 바이블** (1~2일): 색·선·종이·캐릭터 실루엣·화면 구성 규칙을 한 장으로. 그림을 누가 그리든 같은 기준
2. **그릇 만들기** (코드): 그림을 바꿔 끼울 수 있는 자리(스프라이트·애니메이션 프레임) 정리. 지금의 도형 그림은 '임시 그림'으로
3. **세로 조각 한 챕터를 완성도 100%로** (예: 챕터 0): 그림·소리·연출·조작을 공개 수준으로 끝까지. 이게 나머지 챕터의 기준이 된다
4. 나머지 챕터에 같은 수준 적용
5. 외부 플레이 테스트 → 난이도·안내 조정
6. 원작자 문의 → 공개 준비 (배포, 소개 페이지, 짧은 영상)

## 5. 기술 쪽 숙제 (본 제작 중에)
- 저장: 지금은 장면 위치·둘러본 기록·엔딩만. 설정·진행을 묶은 저장 칸
- 원곡 불러오기 표시: 4.6MB를 받는 동안 짧은 로딩 화면
- 휴대폰: 터치로 줄 긁기는 되지만 키보드 코드가 없어 칩 누르기뿐 → 터치 전용 왼손 UI 필요
- 사파리 소리 정책, 저사양 컴퓨터 품질 단계(그림 효과 줄이기 옵션)
- 자동 테스트를 저장소 안(`tests/`)으로
- 공개 빌드: `npm run build` → GitHub Pages 또는 itch.io
