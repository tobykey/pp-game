# 밤샘 작업 보고서 5 (2026-10-23)

목표: MR 음량과 박 밀림 잡기 → 본 제작으로 넘어가기 전에 짚을 것 정리 → **공개 수준의 '진짜 그림'** 작업 시작.

## 1. 바로 해 보기
- `npm run dev` → **새 제목 화면**이 먼저 보인다 (큰 붓글씨 pp, 핑크 낙관, 뒤로 수묵 바다와 배). 조작 안내와 장면 바로 가기는 '조작 안내 · 장면 바로 가기'를 펼치면 있다
- 그림 변화가 잘 보이는 곳: `?step=row`(산·물·배·인물), `?step=hook`(석등), `?step=c1sail`(바위), `?step=c3sea`(등대·돛), `?step=c4solo`(갈라진 마른 바다), `?step=c2umbrella`(표구한 기억 그림), `?step=c5truth`(달빛 든 진실 컷의 방 — 8박 동안 긁지 않기)
- 원곡 음량: `Esc` 메뉴 → **원곡 음량**

## 2. 소리
| 문제 | 원인 | 한 일 |
| --- | --- | --- |
| MR이 너무 크다 | 원음이 합성 기타보다 훨씬 큼 | 기본 크기를 낮추고(설정 100%일 때 0.55, 기본 50%), 메뉴에 원곡 음량 |
| 박이 한 번씩 밀린다 | 드럼·베이스·MR을 예약할 때 오디오 시계의 '현재 시각'을 그대로 썼는데, 이 값이 덩어리로 늦게 갱신되어 예약 시각이 수~수십 ms씩 들쭉날쭉 | 게임 시계와 오디오 시계의 차이를 안정되게 붙잡아 두고 모든 소리를 그 대응으로 예약. 미리 보는 시간도 0.1 → 0.15초 (프레임이 잠깐 끊겨도 늦지 않게) |

## 3. 본 제작 전환 계획 (`docs/production-plan.md`)
- 오래 걸리는 작업 순서: **그림** > 캐릭터 디자인·움직임 > 소리 다듬기 > 플레이 테스트 > 조작·화면 > 공개 준비
- 그림을 진짜 그림으로 바꾸는 세 가지 길과 추천: **배경·물·효과는 코드 수묵(오늘 시작), 캐릭터·기억 그림·컷신·제목 그림은 사람이 그린 그림**(작가 의뢰 또는 직접)
- 사람이 그려야 할 그림 목록(장수·크기·규칙), 본 제작 순서(아트 바이블 → 그릇 만들기 → 한 챕터를 100%로 → 나머지 → 테스트 → 공개)

## 4. 그림 1차 (코드로 그린 수묵)
| 전 | 후 |
| --- | --- |
| 평평한 한지 색 + 점 | 얼룩·긴 닥나무 섬유·바랜 가장자리가 있는 한지 |
| 선 두 줄의 먼 산 | 번지고 고르지 않게 스민 수묵 산 세 겹 + 능선 미점, 끝없이 흐름 |
| 같은 굵기 곡선 물결 | 마른 붓 자국 물결 + 수평선 쪽 옅은 물빛 |
| 검은 다각형 배 | 붓결과 번진 가장자리가 있는 배 + 물에 비친 배 |
| 동그라미·사다리꼴 사람 | 머리칼·옷자락·팔·기타(몸통·울림구멍·넥·헤드)가 있는 붓 실루엣 |
| 납작한 돛과 굵은 테두리 | 한지 천 돛(그늘·주름), 굵기가 변하는 테두리, 바늘땀으로 기운 조각 |
| 기둥 + 삼각형 등불 | 연꽃 받침·지붕돌이 있는 **석등** |
| 다각형 바위 · 막대 등대 | 준법(비탈의 붓결) 먹 바위 · 띠를 두른 돌탑 등대 |
| 테두리만 있는 액자 | 비단 테두리와 나무 축으로 **표구한** 기억 그림 |
| 매끈한 타원 파동 | 군데군데 끊긴 붓 자국 파동 + 안쪽 번짐 |
| 납작한 마른 바다 | 멀수록 작아지는 **갈라진 진흙** 균열망 |
| 평면 방 그림 | 창으로 든 **달빛**이 침대에 내려앉는 진실 컷의 방 |
| 설명서 같은 시작 화면 | **제목 화면** (큰 붓글씨 pp · 낙관 · 세로 글씨, 뒤로 바다가 비침) |
그 밖에: 하늘의 옅은 해, 차분한 장면에 가끔 건너가는 먹 새, 한지 꼬리표 같은 코드 칩, 가벼워진 여섯 줄

## 5. 검증
- 챕터 사이 전환 6곳, 챕터 0·3·5·6 자동 플레이 통과 (오류 없음)
- 번쩍임: 점검 중 두 군데를 찾아 고침 (되감길 때 물벽이 한 프레임에 사라짐 → 서서히, 회상 판이 한 프레임에 꺼짐 → 다 걷힌 뒤). 이제 격돌 ① 최대 8.7, 회상 6.3
- 성능: 사양 낮은 컴퓨터 흉내에서 장면당 11~15ms (60프레임 기준 16.7ms 이내)

## 7. 솔직한 한계
코드로 그린 수묵은 배경·물·효과에는 잘 맞지만, **사람의 표정과 손짓**(캐릭터, 기억 그림 속 장면, 컷신)은 여전히 '붓 실루엣' 수준이다. 공개 수준까지 끌어올리려면 이 부분은 사람이 그린 그림이 들어오는 것이 가장 확실하다 — 그래서 그림이 들어올 자리와 규격을 계획 문서에 정리해 두었다.
