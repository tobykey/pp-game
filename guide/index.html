이런 게임이에요 ABOUT

화면 아래에 기타 줄 여섯 개가 있습니다. 마우스로 줄을 긁으면 소리가 물 위로 번지고, 그 파동이 닿은 곳만 안개가 걷힙니다. 노를 젓는 것도, 길을 비추는 것도, 마음에 박힌 가시를 뽑는 것도 모두 기타를 긁어서 합니다.

이야기는 한 곡을 따라 흘러갑니다. 챕터의 순서, 퍼즐에 쓰는 코드, 박의 빠르기, 셈여림, 반복 기호까지 「피아니시모」의 악보에서 가져왔습니다. 곡을 몰라도 괜찮습니다. 플레이하다 보면 손이 먼저 곡을 기억하게 됩니다.

여섯 줄의 소나

굵은 줄은 멀리 넓게, 가는 줄은 가까이 또렷하게 비춥니다. 세게 긁으면 부수고, 여리게 긁으면 숨은 것이 드러납니다.

박에 맞춰 노 젓기

아래로 긁으면 왼쪽 노, 위로 긁으면 오른쪽 노. 심장 박동에, 드럼에 맞춰 번갈아 저으면 배가 나아갑니다.

먹과 형광

평소엔 한지와 먹의 수묵화. 후렴이 터지는 순간에만 화면이 핫핑크와 노랑으로 덮입니다.

두 번 읽히는 장면

처음엔 그냥 지나친 장면이, 끝까지 가고 나면 전혀 다른 뜻으로 보입니다.

프롤로그 PROLOGUE

바다는 소리를 내지 않았다.

눈을 떴을 때 나는 작은 배 위에 있었고, 품에는 기타가 안겨 있었다.
언제부터 안고 있었는지 모른다. 줄은 여섯 개, 손끝이 기억하는 무게였다.

뱃머리에는 누군가 누워 있었다.
허리에 맨 띠만 안개 속에서 이상할 만큼 선명한 분홍이었다.
한 손이 내 쪽으로 뻗어 있었다. 방금 무언가를 건네고 잠든 사람처럼.

깨워야 한다고 생각했다.
그런데 부를 이름이 떠오르지 않았다.

그래서 줄을 긁었다.
소리가 물 위로 번지자, 안개 속에 길이 보였다.

일곱 개의 바다 CHAPTERS

곡이 연주되는 순서 그대로, 일곱 챕터를 지나갑니다. 전체 약 60분.

  1. 안개피아노 도입 · 훅 · 후렴 1 — 눈을 뜨고, 줄을 긁고, 노 젓는 법을 배운다
  2. 고집의 섬간주 · 1절 — 기억이 걸린 섬들. 그리고 끊어진 줄
  3. 멈춘 시간프리코러스 — 공중에 멈춘 비, 짧게 끊어 치는 소리
  4. 돛후렴 2 — 처음으로 바람을 타는 순간
  5. 마른 바다 → 폭풍훅 + 랩 · 리프 + 랩 — 물이 없는 고요와, 한꺼번에 돌아오는 물
  6. 다시, 그 순간프리코러스 다시 — 같은 기억으로 돌아간다
  7. 깨어남후렴 3 · 코다 — 마지막 가시, 그리고 선택

시작하기 START

지금은 개발 중인 프로토타입이라 내 컴퓨터에서 직접 띄워서 합니다. (챕터 0~4까지 플레이할 수 있어요.)

  1. Node.js를 설치합니다
  2. 게임 폴더에서 터미널을 열고 npm install → npm run dev
  3. 터미널에 나온 주소(http://localhost:5173)를 브라우저로 엽니다
  4. 헤드폰을 끼고 현을 깨우기를 누르면 시작합니다

빛에 민감하다면 시작 전에 Esc 메뉴에서 흔들림·섬광 줄이기를 켜 주세요. 운영체제의 '동작 줄이기'가 켜져 있으면 자동으로 켜집니다.
